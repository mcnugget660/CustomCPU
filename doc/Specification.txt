General Information

16-bit single core CPU

641536 x 16-bit memory

For ease of use, a direct input-output system is built into the CPU itself
Input is queued and fed into the IN register whenever the CPU reads from IN
OUT is immediately written to a file

Registers (25)
 - General purpose registers (0-15)
 - PC register (S0)
 - ADDRESS (S1)
 - HI (S2)
 - LOW (S3)
 - CLOCK (S4)
 - STATUS (S5)
 - IN (S6)
 - OUT (S7)
 - Instruction

STATUS (Least to most significant)
0 - Carry Bit
1 - Arithmetic Exception
2 - IN Waiting
3 - OUT Waiting
4 - OUT TYPE (1 is byte, 0 is halfword)
5 - KILL
6 - COMPARE
7 - BreakPoint
8-15 - ???

All registers are set to 0 on start

Cycle Stages:
    Set Input
    Fetch Instruction
    Execute Instruction (Increment PC if unset)
    Set Output


Instruction Formats

#1 AAAA BBBB BBBB BBBB
A - Opcode
B - constant

#2 AAAA BBBB CCCC CCCC
A - Opcode
B - r1
C - constant

#3 AAAA BBBB CCCC DDDD
A - Opcode
B - r1
C - r2
D - r3

#4 AAAA AAAA BBBB CCCC
A - Opcode
B - r1
C - r2

#5 AAAA AAAA BBBB BBBB
A - Opcode
B - constant

#6 AAAA AAAA AAAA BBBB
A - Opcode
B - r1 or null

Instructions

ADD r1 r2 r3
0001 _ _ _
Sets r1 to the sum of r2 and r3
# Sets carry bit in STATUS

MUL r1 r2 r3
0010 _ _ _
Sets HI and LOW to the signed product of r2 and r3, then sets r1 to the value of LOW

MULU r1 r2 r3
0011 _ _ _
Sets HI and LOW to the unsigned product of r2 and r3, then sets r1 to the value of LOW

DIV r1 r2 r3
0100 _ _ _
Sets HI to signed r2 / r3 and LOW to the remainder, then sets r1 to HI
# Remainder sign depends only on r2
# Divide by 0 sets Arithmetic Error in Status

DIVU r1 r2 r3
0101 _ _ _
Sets HI to unsigned r2 / r3 and LOW to the remainder, then sets r1 to HI
# Divide by 0 sets Arithmetic Error in Status

SETL r1 value
0110 _ _ _
Sets first 8-bits of r1 to value

SETR r1 value
0111 _ _ _
Sets last 8-bits of r1 to value

SET r1 value
1000 _ _ _
Sets r1 to the sign-extended 8-bit value

SETU r1 value
1001 _ _ _
Sets r1 to the 0-extended 8-bit value

JMPR value
1010 _ _ _
Sets PC to the signed sum of PC and value if COMPARE is one

AND r1 r2 r3
1011 _ _ _
Sets r1 to the AND of r2 and r3

OR r1 r2 r3
1100 _ _ _
Sets r1 to the OR of r2 and r3

XOR r1 r2 r3
1101 _ _ _
Sets r1 to the XOR of r2 and r3

ADDI r1 value
1110 _ _ _
Sets r1 to the signed sum of r1 and value
# Sets carry bit in Status

JMPB value
1110 _ _ _
Sets PC to value left-shifted by four if COMPARE is one

MOVS r1 s2
0000 0001 _ X_
Copies the value of special register s2 into general register r1
# First bit of sr is ignored

MOV r1 r2
0000 0010 _ _
Copies the value of r2 into r1

STAT r1 value
0000 0011 _ _
Sets r1 to 1 if the specified status bit is set, otherwise r1 is set to 0

LOAD r1 r2
0000 0100 _ _
Stores the value from memory at r2 in r1 (halfword aligned)

STORE r1 r2
0000 0101 _ _
Stores the value from memory at r2 in r1 (halfword aligned)

LOADB r1 r2
0000 0110 _ _
Stores the least significant byte from memory at r2 into r1 (sign extended)

LOADBU r1 r2
0000 0111 _ _
Stores the least significant byte from memory at r2 into r1 (0 extended)

CMPG r1 r2
0000 1000 _ _
COMPARE is set to is r1 > r2

CMPGE r1 r2
0000 1001 _ _
COMPARE is set to is r1 >= r2

CMPL r1 r2
0000 1010 _ _
COMPARE is set to is r1 < r2

CMPLE r1 r2
0000 1011 _ _
COMPARE is set to is r1 <= r2

STOREB r1 r2
0000 1100 _ _
Stores the least significant byte of r1 into the memory address at r2

SFTL r1 r2
0000 1101 _ _
Shifts r1 r2 bits to the left (fill 0)
# Sets Arithmetic Exception bit in Status if r2 is not within [0, 15]

SFTR r1 r2
0000 1110 _ _
Shifts r1 r2 bits to the right (fill0)
# Sets Arithmetic Exception bit in Status if r2 is not within [0, 15]

SFTRA r1 r2
0000 1111 _ _
Shifts r1 r2 bits to the right (fill sign bit)
# Sets Arithmetic Exception bit in Status if r2 is not within [0, 15]

SADDR r1
0000 0000 0000 _
Sets ADDRESS to r1

JMP r1
0000 0000 0001 _
Sets PC to r1 if COMPARE is one

OUT r1
0000 0000 0010 _
Sets OUT to the value of general register r1
Sets OutType to 0

NOP
0000 0000 0011 _
# Do nothing

KILL
0000 0000 0100 _
Sets KILL bit of STATUS

NEG r1
0000 0000 0101 _
Negates r1

NOT r1
0000 0000 0110 _
Sets r1 to its one-complement

CMPE r1
0000 0000 0111 _
Sets COMPARE to r1 == 0

CMPNE r1
0000 0000 1000 _
Sets COMPARE to r1 != 0

OUTS s1
0000 0000 1001 _
Sets OUT to the value of special register s1
Sets OutType to 0

J r1
0000 0000 1010 _
Sets PC to r1

OUTC r1
0000 0000 1011 _
Sets OUT to the low byte of r1
Sets OutType to 1

DEBUG
0000 0000 1100 _ 
Sets BREAKPOINT to 1 and enables StepThrough mode
