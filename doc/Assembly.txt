Usage

run Assembler.exe file flags

Produces file.asm on success
Invalid directives will produce errors

flags are processed in order, can repeat arbitrarily

optional flags
-o address
Overrides program location (default 0)
-s
Disallows Assembly-only commands
-I filename
includes directives from file
no effect on program offset or relative addressing

Structure

Scopes are groupings of machine instructions and information regarding position dependent constants
A file is an implicit scope

Be cautious when using position-defined constants in commands such as JMPC, SETL, SETR, etc.
as absolute positions may exceed the instruction's width

Main Scope : A program is the machine code generated by the highest level scope
This is the main file

A scope is independent of parent scopes (absolute line references can only access real instructions)
Scope variables can not overlap with parent variables as chain references are dropped (e.g. p1.p2.p3)

Directives

#include filename
Adds macros and subscopes of the mainscope of filename directly to the current scope

#include filename as name
Makes mainscope of filename a subscope to the current scope under name

#using scope
Adds macros and subscopes of scope directly to the current scope

#insert scope
Inserts machine code of scope as name
Scope must be visible

#insertf filename
#insertf filename as name
Same as calling #include and then #insert


Functional inserting
ScopeName() 
resolves to #insert ScopeName

** as name can be excluded but overlapping scope errors and unintended label resolution can occur
** will generate warning - adding a name pushes responsibility onto you, not other files

#define Macro X
Replaces all occurances (seen as a whole word) of Macro with X before interpreting
Macros are applied to all lines within scope
No Macro may start with : b, B, h, H, #
Macros follow keyword guidelines

#define Scope
x1
x2
#endif
Defines a scope (a grouping of machine instructions and their relations)
only copies the lines in between #define and #endif
No second argument -> will error
No Spaces or .

***All macros are evaluated at definition. Changing a macro will not change the multiline-macro's
machine code

#undef Macro
Removes the Macro directive

#data -----
Places data in same relative position
data must fit within a 16-bit block

#dataf filename as name
Places binary data from file in same relative position
Creates a label pointing to begining
data outside of last 16-bit block is diregarded

## Comment
ALL characters past ## are ignored. i.e. ######## works 

Label:
Can not redefine or overlap with keywords
Can be referenced above definition by instructions within the same scope
$LabelName -> evaluates to the position of the machine instruction following the label
additonal use $LabelName[x] -> evaluates to the position of the machine instruction following the label + x

JMPR $LabelName -> will evaluate to offset from Label
JMPB $LabelName -> will evaluate to Label Postion (must be #aligned or error : could be redundant in some cases)

**these commands are the only way to goto the instruction directly AFTER the scope without an error

#x
Replaced with the machine code address of the xth assembly line (this includes directives and empty lines)

#+x 
#-x
Same as above but indicates the line + or - x from the current one

** Only maps to instructions within the same scope

#ENDP
The address AFTER the final machine code Instruction
Only valid in instructions, NOT a macro

#STARTP
The address of the first machine instruction
Only valid in instructions, NOT a macro

#Align16
Ensures that the following instruction falls on a 16-instruction boundary in memory
 - Fills space with NOPS

#Align256
Ensures that the following instruction falls on a 256-instruction boundary in memory
 - Fills space with NOPS

Bit Specification
[h:l] following a constant specifies the relevant bits (inclusive)
h is most significant, l is least significant

Integers can be represented in the following ways

Decimal (eg 43 or -1) : must fit within halfword, positive integers are treated as unsigned
Binary (eg b01 or B10) : Big Endian Ordering, obmitted digits are 0 (leftwards), underscores are ignored
Hexadecimal (eg hA or H4B) : Same above

Characters 'h'
must be a single character, no escape codes

Registers - must be in the following form

rx x => [0, 15]
Rx x => [0, 15]
sx x => [0, 7]
Sx x => [0, 7]
grx x => [0, 15]
GRx x => [0, 15]
srx x => [0, 7]
SRx x => [0, 7]

Command Conventions

gr0 -> memory address
gr1 -> store/load from memory + temp (ignore completly unless very careful)
